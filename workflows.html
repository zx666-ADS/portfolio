四支成片的制作全流程

从创意 brief 到可分发成片，每一支都走「剧本 → 分镜 → 提示词 → AIGC 生图生视频 → Python 自动剪辑/配音 → 交付」的同一套工程化管线。点开任一支查看完整步骤。

竖屏 9:16 健身 Vlog 40s（日常垂类）9 镜 · Python+ffmpeg 自动合成

制作全流程

  1. 选题与人设

    锁定「阿哲」26 岁上班族健身日常人设（《健身Vlog男主人设》），定调第一人称轻松 Vlog，平台抖音/视频号/小红书。

  2. 剧本与分镜

    写《健身Vlog剧本40s日常版》，拆成《健身Vlog分镜脚本》9 镜：换装→下楼→进门→拉伸→弯举→卧推→跑步机→喝水→告别，定景别、运镜、台词与字幕。

  3. 生图提示词

    基于人设写《健身Vlog男主_生图提示词总集》《ChatGPT图片提示词》《运动提示词》，统一画风与人物一致性，作为 AI 生视频的锚点。

  4. AI 生视频

    用即梦/可灵等按镜生成 9 段竖屏素材（720×1280），保留源音轨作环境底噪。

  5. 自动剪辑合成

    build_vlog_final.py 将 9 段按镜号重排、第 7 镜裁剪至 4s、0–28s 硬切 + 28–40s 两段 0.5s 叠化，scale 到 1080×1920，并用 delogo 去除左上角「AI生成」水印。

  6. 字幕烧录

    按时间线脚本用 ffmpeg drawtext 烧录 4 条中文字幕（白字黑边、72px、左下/居中）。

  7. 音频层合成

    build_audio.py + gen_narration.py：edge-tts 云希男声生成 4 句旁白（0/8/28/36s 落位）；numpy 合成 Lo-fi BGM（Fmaj7-Em7-Dm7-Cmaj7, 82BPM）；旁白出现时 BGM 自动 ducking，峰值约 -3.2dB 无破音。

  8. 交付

    成片 mp4 + 制作说明（md/json），含镜号-素材对照、转场、字幕、音频层与去水印说明。

技术栈
  • Python（隔离 venv）
  • ffmpeg（imageio-ffmpeg）
  • edge-tts 配音
  • numpy 合成 BGM
  • ChatGPT 提示词工程
交付物
  • 健身Vlog_成片_40s_带音频.mp4
  • 成片制作说明.md / .json
  • 音频制作说明.md
  • build_vlog_final.py / build_audio.py
关键决策：原「Jianying Auto Editor」skill 需未配置的云端 API 且只输出草稿骨架，无法直接渲染；故改用本地 ffmpeg 管线，成片可离线复现。
竖屏 9:16 咖啡馆手冲 Vlog 40s（生活方式）9 镜 · 人物 [LOCK] 锁定

制作全流程

  1. 选题

    周末慢节奏手冲咖啡 vlog，基调安静治愈、文艺 cinematic 暖调，女主全程 [LOCK] 锁定一致性。

  2. 剧本与分镜

    写《咖啡馆手冲Vlog_剧本40s》→ 拆《咖啡馆手冲Vlog_分镜脚本》9 镜：玄关出门→街步行→推门→称豆→磨豆→注水→闻香→理碎发→挥手，定台词与音效。

  3. 生图/运动提示词

    写《分镜_ChatGPT图片提示词》《分镜_运动提示词》，统一女主（米白开衫、发长、单眼皮/耳钉）与 cinematic 暖调。

  4. AI 生视频

    按镜生成 9 段竖屏素材，镜 3/9 用背影借服装与发长保持可辨识。

  5. 自动合成

    复用 Vlog 管线（build_vlog_final.py 同源逻辑）重排、裁剪、转场、scale 1080×1920、去水印；gen_manual.js 还原剪映时间线便于二次精修。

  6. 字幕与配音

    gen_narration.py 云希旁白按时间码落位（0–4 / 4–13 / 13–23 / 23–32 / 32–40s）；gen_bgm.py 合成适配 BGM。

  7. 一致性验证

    《Skill_v1.1.0_一致性验证报告》逐镜核对人脸、服装、场景一致性，锁脸型/眼型/发型/体型不漂移。

  8. 交付

    成片 mp4 + 分镜/剧本/一致性报告等工程文档。

技术栈
  • Python + ffmpeg 管线
  • edge-tts 配音
  • gen_bgm/gen_narration
  • gen_manual.js（剪映还原）
  • [LOCK] 人物一致性锁
交付物
  • 咖啡馆手冲Vlog_成片_40s_带音频.mp4
  • 剧本 / 分镜脚本 / 图片提示词
  • 一致性验证报告.md
  • pipeline.json

横屏 16:9 魔爪饮料 15s 广告（商业）6 镜 · 品牌 brief 对齐

制作全流程

  1. 创意 Brief

    定位 18–30 岁学生/夜班族/玩家，卖点能量补充；创意「用『困』做钩子，『野性能量』做兑现」。附辩证策略：避开极限运动+重低音的审美疲劳套路，把产品放进熬夜赶缝隙。

  2. 剧本与分镜

    写《魔爪饮料15秒广告剧本》6 镜：揉眼→开罐→畅饮→握拳→快剪→定格，定情绪弧线（疲惫→爆发→满电→定格）与旁白文案。

  3. 生图/生视频提示词

    附 MJ/CogVideoX 可直接用的提示词（开罐特写、畅饮、罐体定格），[LOCK] 锁男主「阿野」人物一致性。

  4. AI 生视频

    按镜生成 6 段 1920×1080 素材；视觉语法前半低饱和手持微抖，开罐后升格、饱和、光斑炸裂。

  5. 自动剪辑

    pipeline.json 驱动 6 镜硬切拼接、字幕烧录（白字黑边，时间点 2.5/5/8/13s），scale 1920×1080 30fps。

  6. 配音与音乐

    edge-tts 云希男声热血版生成 4 句旁白；numpy 合成 BGM（Am-F-C-G 128BPM 电子），旁白出现时 ducking。

  7. 合规复核

    避免「最/第一/唯一」等绝对化用语，核对品牌 slogan 商标授权，发布前复核广告话术。

  8. 交付

    15s 成片 + 剧本 + 制作说明 + 管线配置。

技术栈
  • pipeline.json 配置驱动
  • Python + ffmpeg
  • edge-tts 配音
  • numpy BGM 合成
  • MJ / CogVideoX 生图生视频
交付物
  • 魔爪饮料15秒电视广告_成片_15s_带音频.mp4
  • 魔爪饮料15秒广告剧本.md
  • pipeline.json / scenes.json
  • 成片/制作说明.json
辩证视角：15 秒靠峰值刺激建立记忆，但套路化易疲劳；以「困」这一普遍痛点切入，兼顾记忆点与真实代入感。
横屏 16:9 孙悟空大闹天宫 30s（AI 电影感）4 镜 · character_mode

制作全流程

  1. 选题

    古典神话《西游记》第四至七回，character_mode 强锁人物一致性，国风 guofeng 工笔重彩，红金主色。

  2. 剧本与分镜

    写《孙悟空大闹天宫_剧本30s》4 镜：出世→龙宫夺棒→天兵对决→八卦炉+傲立，44 字旁白，情绪出世→张扬→激战→傲然。

  3. 人物锚定

    写 [LOCK] 一致性锁（猴相/凤翅紫金冠/锁子黄金甲/金箍棒等），生成角色锚图 + 三视图，供逐镜复用。

  4. 文生图

    按《生图生视频交付规格》逐镜写提示词（[LOCK] 逐字复用），1792×1024 16:9 guofeng 工笔重彩，输出 4 张。

  5. 图生视频

    4 段 1080P 运动提示词：推近石猴半身、绕棒旋转、天兵横移、破炉仰拍，对应各镜 target_dur。

  6. 自动合成

    assemble.py 按 scenes.json 拼接：镜 2/3/4 为 0.5s 叠化、镜 1 硬切；字幕 16:9 上沿白字描边。

  7. 配音与 BGM

    edge-tts 生成旁白（本环境 TTS 被拦截则降级静音轨，本地重跑 pipeline.py 可补）；numpy 合成 BGM；混音封装 _带音频.mp4。

  8. 交付

    30s 成片 + 剧本 / 交付规格 / 角色锚图 / 三视图。

技术栈
  • character_mode 一致性锁
  • 文生图 + 图生视频
  • assemble.py 自动拼接
  • edge-tts 配音
  • numpy BGM 合成
交付物
  • 孙悟空大闹天宫_成片_30s_带音频.mp4
  • 剧本30s / 生图生视频交付规格
  • 角色锚图 + 三视图
  • scenes.json / pipeline.json
